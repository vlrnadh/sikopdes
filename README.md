# SiKopdes
Sistem Informasi Koperasi Desa Merah Putih.(menggunakan vibe codding)

## Deskripsi
SiKopdes merupakan sistem informasi  untuk membantu
pengelolaan operasional koperasi desa.

## Fitur
- Pengelolaan stok barang
- Transaksi kasir
- Pengelolaan data produk
- Laporan transaksi

## Teknologi
- PHP
- MySQL
- HTML, CSS, dan JavaScript

## Cara Menjalankan
1. Simpan proyek di folder htdocs XAMPP.
2. Jalankan Apache dan MySQL.
3. Siapkan database jika aplikasi membutuhkannya.
4. Buka http://localhost/sikopdes/
